# Claude — критический аудит копии и визуала (независимый)

## A. ЧИСЛО-ШУМ (диапазоны через тире → одно уверенное число)
Главная проблема. Диапазоны читаются как «мы сами не знаем» + создают визуальный мусор.

### Roles — stat-callouts
- `+15–30%` конверсия → **+24%**
- `+10–25%` средний чек → **+18%** (= число на дашборде)
- `1–3 мес` окупаемость → **2 мес** (= калькулятор 2,6)
- `5–20×` быстрее обработка → **×12**
- `−30–70%` ручной работы → **−60%**
- `<1%` ошибок → оставить (чистое утверждение, не диапазон)
- `−70–90%` ручной отчётности → **−85%**
- `5–10×` быстрее аналитика → **×8**
- `2–3 мин` цикл анализа → **2 мин**
- `+5–20%` маржа → **+12%** (= дашборд +12%)
- `−80–90%` ручной нагрузки → **−85%**

### Дашборды (inline)
- `↑ 10–25%` (средний чек) → **↑ 18%**
- `5–20×` (скорость, 2 места) → **×12**
- `было ~3 дня` → **было 3 дня** (убрать ~)
- `5–20%` (маржа delta, 2 места) → **+12%**
- `2–3 мин` / `+5–20%` (сводка цен) → **2 мин** / **+12%**

### Калькулятор / exp
- `~750 тыс. ₽` → убрать `~` (оценка и так помечена дисклеймером)
- `До 25% ФОТ · 1–6 мес.` → **−25% расходов на ФОТ.** (убрать «До» и диапазон, квартал уже в заголовке)

## B. СЛАБАЯ / ИИ-КОПИЯ (карточки — пользователь прямо указал)
- `609 FTE ручного труда — на автономных агентах.` → жаргон (FTE, «автономные агенты»), не предложение. → **609 ставок ручной работы уже перевели на цифровых сотрудников.**
- `Закрытый контур · наружу только токены.` → техножаргон, CEO не поймёт. → **Данные остаются в вашем контуре — наружу ничего не уходит.**
- `Клиент чувствует личное внимание.` → пустой ИИ-штамп. → **Мгновенный ответ каждому — и память обо всех прошлых обращениях.**
- Отзыв #1: `на 1/4 сократили … — при росте всех показателей` → **Через пару месяцев зарплатный фонд отдела сократился на четверть — и это при росте продаж.**
- Отзыв #4: `персонализации добавилось` → коряво. → **Боялись получить бездушного робота. Вышло наоборот: клиенты перестали ждать ответа часами, а каждый диалог стал персональнее.**
- Roles HR: `видит только живых кандидатов` → двусмысленно. → **видит только заинтересованных кандидатов.**

## C. ТЕРМИНОЛОГИЯ
- `Кем станет робот в вашей компании` → «робот» рассинхрон с «цифровой сотрудник». → **Кем станет цифровой сотрудник в вашей компании**
- `−33 FTE` / `609 FTE` — FTE-жаргон. Заменить FTE→«ставок» в видимой копии.

## D. ВИЗУАЛ
- После замены диапазонов на одиночные числа дашборды и stat-блоки станут чище.
- Тире-диапазоны были основным источником «грязи».
