Замкнутый периметр.
Сертифицировано.

L3 шифрует и маскирует входящие данные. L4 обрабатывает в изолированном контуре. L5 выдаёт только метрики — никогда персональных данных. Данные не покидают вашего периметра ни на одном уровне.

сертификации
ФСБ КС3 · ФСТЭК · ISO/IEC 27001 · 152-ФЗ
Маскирование
Контроль доступа
Резервирование
PII заменяются на токены `[N_PERSON]`, `[N_PHONE]`, `[A_MODEL]` до выхода из L3. Восстановление — только при возврате в вашу CRM.
Доступ по принципу least-privilege. RBAC + scope ограничен инстансом сотрудника. Каждый запрос — в audit-trail.
Hot-standby реплика данных по контуру L3. RTO ≤ 5 мин, RPO ≤ 30 сек. Без ротации ключей шифрования наружу.

11Функции платформы

Безопасность.По умолчанию.

Маскирование
на L3.

Персональные данные маскируются в момент входа в платформу. AI-агенты работают только с anonymized tokens, не с настоящими ФИО, телефонами, адресами.

Дешифровка — только в момент выхода обратно в вашу CRM, в защищённом коннекторе. На стороне HyperPlatform plain-text данные не существуют.

L3 → L4 [redacted] active 100 %

Контроль
доступа.

RBAC на уровне каждого digital worker. Куратор-человек подтверждает каждый класс операций. Worker не может выйти за периметр своих прав даже при ошибке prompt-injection.

Audit-trail неизменяем: каждый шаг каждого worker — в hash-chain журнале, выгружается в ваш SIEM.

rbac [locked] audit 8 / 8

Резервирование.
Hot-standby.

Каждый worker реплицируется на standby-инстанс в отдельной availability zone. RTO < 60 сек, RPO < 5 сек. Failover автоматический, без вмешательства куратора.

Снапшоты состояния каждые 4 часа в холодное хранилище с retention 7 лет.

rto < 60 sec retention 7 лет
