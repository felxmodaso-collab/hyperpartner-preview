## Что это
Отдельная независимая страница под аккредитацию ИТ-компании в Минцифры для ПО
**«Хайперплатформ» / HyperPlatform** (платформа для чат-ботов). Покрывает чек-лист
«Требования Минцифры к ИТ-сайтам». Заказчик — ООО «Хайперпартнер».

## Файлы
- `platform/index.html` — главная страница (деливерабл). Светлая документ-стайл, бренд HyperPartner
  (IBM Plex Sans, forest #16302B, бронза #C79A7E, paper #F5F4F0). Хедер/футер консистентны с осн. сайтом.
- `platform/user-guide.html` — Руководство пользователя HyperPlatform v1.0.0 (полный текст из
  «Документация по эксплуатации ПО.docx»), sticky-оглавление, `@media print` (Ctrl-P → PDF).
- `docs/hyperplatform-features.pdf` — копия PDF функц.характеристик заказчика (для скачивания).
- `_source/` — извлечённые исходники ТЗ + руководства.

## Reveal-анимация
Прогрессивное улучшение: контент виден без JS (`.rv{opacity:1}`); анимация только при
`html.anim` (JS добавляет при разрешённом motion). Критично для комплаенса — обязательный контент
не спрятан за JS.
